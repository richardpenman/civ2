OpenCiv2

Civilization II Multiplayer Gold Edition, rebuilt to run in your browser. It plays with your own copy of the game: choose the folder Civilization II is installed in (the one with Civ2Art.dll and RULES.TXT). The files are copied into this browser's storage, and never leave your computer; your saved games are kept there too.

or drop the folder (or the .zip) here

The game needs to be installed: its CD or a disc image of it is not enough here (the desktop version of OpenCiv2 can set the game up from those, and its game folder can then be chosen). Music plays if the folder has it (Music/Track02.ogg ..., as the desktop version's set-up makes from the CD). Single player only: network games are not available in the browser.

The game files are in this browser.
